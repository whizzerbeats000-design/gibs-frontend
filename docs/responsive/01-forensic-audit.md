## 5. Font audit

`index.html` carries a Google Fonts `<link>` for **Fraunces, Space Grotesk, Instrument Serif**; `src/index.css` `@import` also requests **Instrument Serif + Inter + Libre Baskerville**. Both execute (network log shows two css2 requests + 5 woff2 loads). `document.fonts.load()` confirms all five families report loaded; h1 resolves to `"Instrument Serif"` and `.card-title` to `"Fraunces"`. **The earlier "Fraunces/Space Grotesk fall back to system" observation is obsolete** — the two-request setup now loads all five. One redundancy remains (`Font-A4`).
